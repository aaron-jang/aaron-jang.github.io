## 1. Ulanzi 픽셀 시계란

Ulanzi 픽셀 시계는 **ESP32 기반의 WiFi 연결 LED 매트릭스 시계**입니다. 단순한 탁상시계를 넘어서, 픽셀 아트 애니메이션을 표시하고, 앱으로 원하는 정보를 커스텀할 수 있는 것이 가장 큰 매력입니다.

주요 용도를 정리하면 다음과 같습니다.

- **시계 / 날짜 / 날씨** 표시 (기본)
- **SNS 팔로워 카운터** (유튜브, 트위치, 인스타그램 등)
- **포모도로 타이머 / 카운트다운 / 스톱워치**
- **점수판** (스포츠 경기 등)
- **커스텀 픽셀 아트** 애니메이션
- **스마트홈 알림 디스플레이** (AWTRIX 펌웨어 적용 시)

약 5만 원대부터 시작하는 가격에 이 정도 기능이면, 가성비 끝판왕이라 할 만합니다.

## 2. TC001 스펙 상세

TC001은 2023년에 출시된 1세대 모델로, 컴팩트한 크기와 저렴한 가격이 강점입니다.

| 항목 | TC001 |
|------|-------|
| 디스플레이 | 32 x 8 RGB LED (256 픽셀) |
| 프로세서 | ESP32 |
| 배터리 | 4,400mAh (최대 5시간) |
| 연결 | WiFi, USB-C |
| 입력 | 버튼 |
| 스피커 | 없음 |
| 크기 | 약 200 x 63 x 30mm |
| 가격 | **$45.99** (약 6만 원대) |

32x8 해상도는 한 줄 텍스트와 작은 아이콘을 동시에 표시하기에 딱 맞는 크기입니다. USB-C로 전원을 공급받으며, 내장 배터리 덕분에 충전 후 몇 시간은 무선으로 사용할 수 있습니다.

TC001의 장점은 명확합니다.

- **가격이 저렴합니다** ($46 수준)
- **컴팩트해서 어디든 놓기 좋습니다**
- **오픈소스 커뮤니티가 활발합니다** (AWTRIX 펌웨어 초기부터 지원)
- **4,400mAh 배터리**로 TC002보다 용량이 큽니다

## 3. TC002 스펙 상세

TC002는 TC001의 후속 모델로, 디스플레이 크기와 기능 모두 대폭 업그레이드되었습니다.

| 항목 | TC002 |
|------|-------|
| 디스플레이 | 52 x 16 RGB LED (832 픽셀) |
| 프로세서 | ESP32-S3 |
| 배터리 | 3,600mAh (3.7V / 13.32Wh) |
| 연결 | WiFi, MQTT, Bluetooth |
| 입력 | **로터리 노브 + 버튼 3개** |
| 스피커 | **내장 (TTS, 인터넷 라디오 지원)** |
| 충전 | **마그네틱 충전 스탠드** |
| 가격 | **$109.95** (약 15만 원대) |

832 픽셀로 TC001 대비 **3배 이상의 해상도**를 제공합니다. 덕분에 2줄 텍스트 + 16x16 아이콘을 동시에 표시할 수 있어, 정보 밀도가 크게 올라갑니다.

TC002에서 새로 추가된 핵심 기능들입니다.

- **스피커 내장**: TTS 음성 합성, 인터넷 라디오, 알림 사운드 재생
- **로터리 노브**: 직관적으로 메뉴 탐색과 볼륨 조절 가능
- **마그네틱 충전**: 충전 스탠드에서 분리해 휴대 가능
- **Bluetooth 게임패드 연동**: 간단한 게임까지 즐길 수 있습니다
- **음성 어시스턴트**: Home Assistant 연동 시 음성 명령 처리
- **9개 내장 도구**: 세계 시계, 집중 타이머, 날씨, 공지판, 스톱워치 등
- **Ulanzi Studio 앱**: 전용 앱으로 손쉽게 설정 가능

## 4. TC001 vs TC002 한눈에 비교

두 모델의 차이를 표로 정리했습니다.

| 비교 항목 | TC001 | TC002 |
|-----------|-------|-------|
| 해상도 | 32 x 8 (256px) | 52 x 16 (832px) |
| 텍스트 줄 수 | 1줄 | 2줄 |
| 프로세서 | ESP32 | ESP32-S3 |
| 스피커 | 없음 | 내장 |
| 입력 방식 | 버튼 | 로터리 노브 + 버튼 |
| Bluetooth | 없음 | 지원 |
| MQTT | 커스텀 펌웨어 필요 | 기본 지원 |
| 음성 어시스턴트 | 미지원 | 지원 |
| 배터리 | 4,400mAh | 3,600mAh |
| 충전 방식 | USB-C 직접 | 마그네틱 스탠드 |
| 가격 | $45.99 | $109.95 |

**TC001이 맞는 사람**: 시계, 날씨, 팔로워 카운터 정도의 기본 기능만 필요하고, 가성비를 중시하는 분. 이미 AWTRIX 세팅을 갖추고 있는 분.

**TC002가 맞는 사람**: 넓은 디스플레이에 더 많은 정보를 표시하고 싶은 분. 스피커를 활용한 TTS 알림이나 인터넷 라디오를 원하는 분. Home Assistant 연동을 본격적으로 활용할 분.

## 5. AWTRIX NG란

**AWTRIX NG(Next Generation)**는 Blueforcer가 개발한 오픈소스 펌웨어로, Ulanzi 픽셀 시계의 잠재력을 100% 끌어내는 핵심 소프트웨어입니다.

기본 Ulanzi 펌웨어도 쓸 만하지만, AWTRIX NG를 설치하면 다음과 같은 기능이 추가됩니다.

- **Web UI**: 브라우저에서 직접 시계를 설정하고 제어
- **HTTP API + MQTT**: 외부 시스템과 자유롭게 연동
- **Berry 스크립팅**: 커스텀 로직을 직접 작성 가능
- **앱 로테이션**: 시계, 날씨, 센서 데이터 등이 자동으로 번갈아 표시
- **인터넷 라디오** (TC002): 스피커를 활용한 라디오 스트리밍
- **Bluetooth 게임패드** (TC002): 간단한 게임 실행

AWTRIX NG는 TC001, TC002, 직접 조립한 ESP32/ESP32-S3 매트릭스 모두 지원합니다. 2026년 11월 기준 최신 릴리스에서 TC001과 TC002 모두 공식 지원되고 있습니다.

### AWTRIX NG 설치 방법

TC002 기준으로 설치 과정은 간단합니다.

1. [AWTRIX NG 공식 문서](https://blueforcer.github.io/awtrix-ng/)에 접속
2. 웹 플래셔로 펌웨어 설치 (USB 연결 후 브라우저에서 진행)
3. WiFi 설정 후 Web UI 접속
4. MQTT 브로커 주소 입력 (Home Assistant 연동 시)

별도의 개발 환경 없이 브라우저만으로 설치할 수 있어서 초보자도 어렵지 않습니다.

## 6. Home Assistant 연동 활용법

AWTRIX NG의 진가는 **Home Assistant와 연동**할 때 드러납니다.

### 자동 MQTT Discovery

AWTRIX NG 펌웨어에서 MQTT 브로커를 설정하면, Home Assistant가 자동으로 디바이스를 인식합니다. 별도 설정 없이 버튼, 센서, 밝기, 볼륨 등이 HA 엔티티로 등록됩니다.

### 주요 연동 시나리오

활용 예시를 몇 가지 소개합니다.

- **실시간 센서 표시**: 실내 온습도, 전력 소비량, 미세먼지 등을 시계에 표시
- **알림 디스플레이**: 택배 도착, 세탁기 완료, 문 열림 등 이벤트를 픽셀 아이콘과 함께 표시
- **TTS 음성 알림** (TC002): "세탁이 완료되었습니다" 같은 음성 알림을 시계 스피커로 재생
- **대시보드 미러링**: HA 대시보드에서 시계 화면을 실시간으로 확인 (약 1초 간격 업데이트)
- **버튼 Webhook**: 시계의 물리 버튼을 눌러 HA 자동화 트리거 (예: 조명 토글)
- **전력 모니터링**: 전력 소비량을 프로그레스 바와 색상 임계값으로 시각화

커뮤니티에서 다양한 **블루프린트**(자동화 템플릿)를 공유하고 있어서, 복잡한 YAML을 직접 작성하지 않아도 됩니다.

## 7. 구매 팁과 주의사항

구매 전 알아두면 좋은 점들을 정리했습니다.

- **TC001은 알리익스프레스에서 $30~40대**에 구할 수 있는 경우가 많습니다. 세일 기간을 노리면 더 저렴합니다.
- **TC002는 Ulanzi 공식몰 기준 $109.95**입니다. 아마존에서도 비슷한 가격대에 판매합니다.
- AWTRIX NG 펌웨어를 올리면 **기본 Ulanzi 펌웨어는 덮어씌워집니다**. 되돌리고 싶으면 Ulanzi Studio에서 기본 펌웨어를 재설치할 수 있습니다.
- TC002의 마그네틱 충전 스탠드는 편리하지만, **별도 USB-C 직접 충전은 되지 않으므로** 스탠드 분실에 주의하세요.
- Home Assistant 연동을 위해서는 **MQTT 브로커**(Mosquitto 등)가 미리 설치되어 있어야 합니다.

## 8. 마무리

Ulanzi TC001은 6만 원대에 픽셀 시계의 매력을 경험할 수 있는 가성비 모델이고, TC002는 스피커, 로터리 노브, 3배 넓은 디스플레이로 제대로 업그레이드된 모델입니다. 여기에 AWTRIX NG 펌웨어를 올리면 단순한 탁상시계가 Home Assistant와 연동되는 스마트홈 디스플레이로 변신합니다.

특히 이미 Home Assistant를 사용하고 계신 분이라면, TC002 + AWTRIX NG 조합을 강력히 추천합니다. 책상 위에서 실시간으로 집안 상태를 확인하고, 음성 알림까지 받을 수 있는 경험은 생각보다 만족도가 높습니다.

감사합니다.
