안녕하세요. 수수입니다. <br />

1부에서는 뮤즈·닷·그록봇·듀엣·피클이 지향하는 역할을 살펴봤습니다. 이번에는 **한국에서 쓸 수 있는지, 비용을 어떻게 읽어야 하는지, 어디까지 권한을 넘길지**를 정리해보겠습니다.

> **선택 전에 확인할 네 가지**
>
> - **접근:** 한국 계정에서 필요한 기능이 열리는가?
> - **비용:** 구독 외 사용량과 외부 결제는 얼마인가?
> - **권한:** 발송·예약·결제 전에 어디서 멈추는가?
> - **기록:** 기억과 로그인 정보를 관리할 수 있는가?
{: .prompt-tip }

*2026.10.31 공식 자료 기준. 가입·결제를 직접 시험하지 않았으며, 뒤의 비교 과제는 실험 계획입니다.*

## 🇰🇷 한국어 지원과 한국에서의 완수는 다르다

한국어로 대답한다고 한국 사이트의 본인 인증이나 결제까지 처리할 수 있는 것은 아닙니다. 다음 단계를 따로 확인해야 합니다.

1. **접근:** 한국 계정으로 가입하고 기능을 활성화할 수 있는가?
2. **연결:** 필요한 사이트나 앱에 로그인할 수 있는가?
3. **처리:** 조회에 그치지 않고 예약·신청·변경까지 가능한가?
4. **검증:** 완료 번호나 원본 화면으로 결과를 확인할 수 있는가?

| 서비스 | 접근 조건과 확인할 점 |
|---|---|
| **[뮤즈](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/)** | 미국 출시 안내. 한국 계정 제공·국내 앱 연동은 별도 확인 |
| **[닷](https://learn.chatgpt.com/docs/dots#access)** | 대상 유료 플랜에 순차 제공. 내 계정 활성화 여부 확인 |
| **[그록봇](https://docs.x.ai/grok-bot/overview)** | 유료 구독 경로별 제공. 포함 기능·지역 제한 확인 |
| **[듀엣](https://support.claude.com/en/articles/17631495-get-started-with-claude-duet)** | 미국 유료 개인 계정 대상 대기자 프리뷰 |
| **[피클](https://apps.apple.com/kr/app/id6795790129)** | 한국 스토어·국내 기능 안내 확인. 가입 조건·한도는 앱에서 확인 |

**피클은 지역 안내를 함께 확인하세요.** 공개 영문 약관의 미국 이용 조건과 한국 스토어 안내가 달랐습니다. 가입 시 적용되는 지역 약관과 실제 연결 화면을 기준으로 판단해야겠습니다. [공개 약관](https://www.pickle.com/terms-of-service)

## 💳 월 구독료보다 중요한 총비용

비교할 때는 **구독료 + 추가 사용량 + 외부 거래 비용**을 나눠야 합니다. AI를 무료로 써도 기차표나 상품 가격까지 무료가 되는 것은 아닙니다.

| 서비스 | 비용 자료를 읽을 때 볼 부분 |
|---|---|
| 뮤즈 | 무료 범위와 더 많은 이용을 위한 구독 조건 |
| 닷 | 대화와 위임한 Work·Codex 작업의 사용량 구분 |
| 그록봇 | 어떤 구독으로 접속하는지와 그 구독의 사용량 조건 |
| 듀엣 | 브리핑·백그라운드 점검도 기존 플랜 사용량에 포함 |
| 피클 | 무료 다운로드, 인앱 상품, 실제 가입 가능한 상품의 차이 |

닷은 대화와 별개로 위임한 작업이 해당 제품의 사용량에 반영된다고 안내합니다. 듀엣은 프리뷰에서 추가 이용료 없이 개인 유료 플랜에 포함되지만, 백그라운드 작업도 한도를 소비한다고 설명합니다. [닷 사용량](https://learn.chatgpt.com/docs/dots#access), [듀엣 요금·한도](https://support.claude.com/en/articles/17631495-get-started-with-claude-duet)

피클의 한국 스토어에는 한도 초기화 티켓과 구독 항목이 함께 표시됩니다. 이 목록만으로 현재 계정의 요금제를 확정하면 안 됩니다. **구매 직전 앱의 조건과 청구 화면**을 기준으로 봐야 합니다. [스토어 인앱 구입 정보](https://apps.apple.com/kr/app/id6795790129)

제가 실제로 비교한다면 한 달 가격과 함께 **검토를 마친 유효한 결과물 1개당 비용**도 적어볼 것 같습니다. 결과가 틀려 사람이 처음부터 다시 해야 했다면 저렴한 구독도 별 도움이 되지 않기 때문입니다.

## 🔐 같은 승인 기능도 작동 방식이 다르다

| 서비스 | 승인·통제 방식 |
|---|---|
| **[뮤즈](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/)** | Sentinel이 외부 행동 검토 |
| **[닷](https://learn.chatgpt.com/docs/dots)** | 앱 권한·자동 검토·사용자 규칙 |
| **[그록봇](https://docs.x.ai/grok-bot/approvals-security-and-privacy)** | Auto Review와 자동 허용·먼저 질문 규칙 |
| **[듀엣](https://support.claude.com/en/articles/17631495-get-started-with-claude-duet)** | 메시지·결제·서명·삭제 전 승인 |
| **[피클](https://apps.apple.com/kr/app/id6795790129)** | 중요한 예약·결제 전 승인, 과정 확인 |

이 기능들이 있다는 이유만으로 모든 행동을 매번 물어본다고 생각해서는 안 됩니다. 자동 허용 범위, 저장된 결제수단, 사용자가 이미 준 지시와 조직 정책 등이 작동에 영향을 줍니다.

블로그 발행이라면 “작업해줘”보다 **초안 저장·파일 수정·커밋·푸시·배포 중 어디까지 맡기는지** 정하는 편이 명확합니다. 아래는 제가 활용할 만한 요청 예시입니다.

> 관련 공식 자료를 조사해 초안을 작성하고 빌드해줘. 외부 게시와 메시지 전송은 초안과 변경 내용을 검토한 뒤 진행하자.

이는 각 회사의 정해진 명령어가 아니라 업무 범위를 표현하는 예시입니다.

## 🧠 대화·기억·로그인은 따로 관리하기

삭제할 대상을 나누면 이해하기 쉽습니다.

- **대화:** 주고받은 메시지와 첨부 자료.
- **기억:** 대화에서 추려 저장한 선호와 맥락.
- **파일·로그인:** 클라우드에 남은 작업물과 접속 세션.
- **연결 권한:** 외부 앱에 접근할 수 있는 권한.

그록봇은 봇들이 한 컴퓨터를 공유하며, 봇을 삭제해도 공유 파일과 브라우저 세션이 사라지는 것은 아니라고 명시합니다. 듀엣도 앱 연결을 해제한 뒤 이전 대화에서 얻은 기억은 남을 수 있다고 설명합니다. [그록봇 데이터 제거 안내](https://docs.x.ai/grok-bot/approvals-security-and-privacy), [듀엣 연결 관리](https://support.claude.com/en/articles/17631495-get-started-with-claude-duet)

닷 역시 작업·대화·기억의 관계를 별도로 설명합니다. 사용을 중단할 때는 현재 작업과 예약된 작업을 나누어 확인할 필요가 있습니다. [닷의 작업과 기억](https://learn.chatgpt.com/docs/dots/tasks-and-memory)

서비스를 바꾸거나 계정을 정리할 때 저는 다음을 확인하겠습니다.

- 잘못된 기억을 직접 읽고 수정할 수 있는가?
- 연결 해제와 예약 작업 취소를 따로 해야 하는가?
- 저장한 파일과 로그인 세션도 제거되는가?
- 작업 기록과 스킬을 내보내 다음 도구에서 쓸 수 있는가?

공개 자료만으로 모든 서비스의 내보내기 범위를 확인하지는 못했습니다. 따라서 특정 서비스가 완전한 이식성을 제공한다고 가정하지 않았습니다.

## 🛡️ 학습 제외와 운영자 접근은 별개

개인정보를 볼 때는 **모델 학습, 광고 이용, 운영자의 접근, 연결된 서비스로의 전달**을 구분해야 합니다.

뮤즈는 광고 시스템과의 분리와 학습 이용 거부 선택을 설명합니다. 그록봇은 학습 이용 선택이 적용되는 계정 설정을 따르고, Legacy Privacy Mode를 지원하지 않는다고 안내합니다. [Meta 안내](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/), [Grok Bot 개인정보 설정](https://docs.x.ai/grok-bot/approvals-security-and-privacy)

피클의 개인정보 안내는 대화·기억의 모델 학습 및 광고 이용을 하지 않는다고 설명하면서도, 지원과 안전 대응 등에 권한 있는 직원이 접근할 수 있다고 밝힙니다. **학습 제외와 운영자 접근 불가는 다른 조건**인 셈입니다. 구체적인 보관·삭제 조건은 가입 시 적용되는 정책을 확인해야 합니다. [피클 개인정보 안내](https://www.pickle.com/privacy?pubDate=20260102)

## 🧪 직접 비교한다면 이렇게 기록하겠습니다

아직 아래 시험을 진행하지 않았습니다. 향후 실사용 편을 만든다면 같은 원본 자료와 조건으로 다음을 비교할 수 있습니다.

| 비교 과제 | 확인할 완료 증거 |
|---|---|
| **영상 기반 글 초안** | 주장과 원본 출처가 연결된 초안 |
| **배포 실패 조사** | 로그 근거와 재현 결과 또는 수정안 |
| **예약 후보 조사** | 조건·가격·가용 여부와 확인 시각 |
| **며칠 뒤 자료 갱신** | 이전 결과에서 달라진 항목과 근거 |

예약 과제는 먼저 실제 예약 없이 후보 조사까지만 비교하면 부담이 적습니다. 실행 단계까지 시험할 때는 동일한 승인 조건을 두면 됩니다.

결과는 다음 다섯 상태로 기록하겠습니다.

**성공 · 부분 완료 · 실패 · 미지원 · 승인 대기**

여기에 **시간·비용·사람이 개입한 횟수**를 더합니다. 미지원과 실행 실패를 구분해야 비교가 공정해집니다.

## 💭 마치며: 작은 일 하나로 선택 기준을 확인하자

제가 먼저 시험해보고 싶은 것은 자주 반복하지만 결과를 확인하기 쉬운 일입니다. 자료 조사라면 출처를, 문서라면 수정된 파일을, 예약이라면 확정 내용을 확인할 수 있어야겠습니다.

생활 대행에 관심이 있다면 뮤즈·피클의 관련 기능을, 지속적인 프로젝트라면 닷을, 여러 역할의 협업이라면 그록봇을, 메일과 업무 자료라면 듀엣을 살펴보는 것이 출발점이 될 수 있습니다. 이는 기능에 따른 선택 방향이며 성능 순위는 아닙니다.

지금 필요한 비교는 “어느 AI가 무조건 최고인가”보다 **내가 반복하는 일 하나를 맡겼을 때 시간을 얼마나 아끼고 결과를 얼마나 확인할 수 있는가**라고 생각합니다.
