## 1. 피클이란?

피클은 한국인 창업팀이 실리콘밸리에서 만든 **생활 밀착형 AI 에이전트 앱**입니다.

기존 AI 챗봇과의 가장 큰 차이점은 **직접 행동한다**는 것입니다. 질문에 답하는 데서 그치지 않고, 전화를 걸고, 웹사이트에 접속해서 주문하고, 결제까지 처리합니다.

| 항목 | 내용 |
|---|---|
| **개발사** | Pickle Company |
| **창업자** | Daniel Park(박채근), Emmett Kim, Ho Jin Yu, Sanio Jung |

## 2. 핵심 기능

### 2-1. 전화 대행

피클의 가장 인상적인 기능입니다.

- 통신사에 전화해서 **요금제 변경, 환불 요청**
- 고객센터 연결 → 대기 → 용건 전달까지 AI가 처리
- 사용자는 결과만 확인하면 됨

앱스토어 리뷰에서 "전화를 너무 잘해요"라는 평가가 나올 정도로, 다른 AI 서비스에서 실패한 전화 업무를 피클이 성공적으로 처리하고 있습니다.

### 2-2. 쇼핑 & 결제

- **쿠팡, 다이소몰** 등에서 상품 검색, 주문, 결제
- 배송 조회, 주문 취소도 앱 내에서 처리
- 결제 시 **사용자 최종 승인 필수** — AI가 맘대로 결제하지 않음

### 2-3. 예약 & 예매

- **식당, 병원, 숙소** 예약
- **KTX, 항공권** 예매
- 매진된 KTX의 **취소표 모니터링** — 좌석이 나면 알림 후 즉시 예매

### 2-4. 서비스 연동

피클이 한국에서 특히 주목받는 이유는, 한국인이 실제로 쓰는 서비스들과 연동되기 때문입니다:

| 카테고리 | 연동 서비스 |
|---|---|
| **포털/메신저** | 네이버, 카카오톡 |
| **이메일/캘린더** | 지메일, 구글 캘린더 |
| **쇼핑** | 쿠팡, 다이소몰 |
| **교통** | KTX, 항공사 |
| **공공** | 정부24 |
| **기타** | 통신사, 배달앱, 보험 |

피클의 **클라우드 브라우저**가 연결된 계정으로 웹사이트에 접속해서 작업을 수행합니다.

### 2-5. 에이전트 간 대화 (피클 x 피클)

가장 독특한 기능입니다.

내 피클과 친구의 피클이 **서로 대화해서 일정을 조율**합니다.

> "이번 주 토요일 저녁에 친구랑 밥 먹고 싶어"

이렇게 말하면:
1. 내 피클이 친구의 피클에게 메시지 전송
2. 두 에이전트가 서로 일정 확인
3. 가능한 시간과 장소를 합의
4. 양쪽 사용자에게 확인 요청

카톡으로 10번 주고받을 걸 피클끼리 알아서 처리해줍니다.

## 3. 작동 원리

피클은 단순한 챗봇이 아니라 **실제 행동하는 AI 에이전트**입니다:

```
사용자 요청
  ↓
피클이 작업 계획 수립
  ↓
클라우드 브라우저로 웹사이트 접속 / 전화 발신
  ↓
작업 실행 (검색, 입력, 클릭, 통화)
  ↓
고위험 작업(결제, 예약)은 사용자 승인 요청
  ↓
완료 후 결과 보고
```

핵심은 **클라우드 브라우저**입니다. 사용자가 연결한 계정(쿠팡, 네이버 등)으로 실제 웹사이트에 접속해서, 사람이 하는 것처럼 클릭하고 입력하고 결제합니다.

## 4. ChatGPT, Manus와 뭐가 다른가?

| | **피클** | **ChatGPT** | **Manus** | **메타 뮤즈** |
|---|---|---|---|---|
| **핵심** | 한국 생활 서비스 대행 | 대화/지식 | 범용 업무 자동화 | SNS 기반 AI 비서 |
| **전화 대행** | O | X | X | X |
| **쇼핑/결제** | O (쿠팡 등) | X | X | 제한적 |
| **KTX/항공 예매** | O | X | X | X |
| **한국 서비스 연동** | 네이버, 카카오, 정부24 | X | X | X |
| **에이전트 간 대화** | O | X | X | X |
| **타깃 시장** | 한국 | 글로벌 | 글로벌 | 미국 |

피클의 강점은 명확합니다: **한국 생활에 특화**되어 있다는 것. 네이버, 카카오, 쿠팡, KTX 같은 한국 서비스와의 깊은 연동은 글로벌 AI 서비스에서는 기대하기 어렵습니다.

## 6. 장단점

### 장점

- **진짜 행동하는 AI** — 전화, 주문, 예약을 실제로 수행
- **한국 서비스 특화** — 네이버, 카카오, 쿠팡, 정부24 연동
- **에이전트 간 소통** — 친구의 피클과 자동 일정 조율
- **안전장치** — 결제/예약 시 사용자 최종 승인 필수
- **KTX 취소표 모니터링** — 매진 열차도 잡을 수 있음

### 단점

- **iOS만 지원** — 안드로이드 앱은 아직 미출시
- **연동 서비스 제한** — 모든 서비스를 지원하지는 않음
- **AI 실수 가능성** — 복잡한 요청에서 오류 가능
- **개인정보 민감** — 쇼핑몰, 통신사 계정을 연결해야 하므로 신뢰 필요

## 마무리

피클은 **"AI가 대화만 하는 시대는 끝났다"**는 걸 보여주는 앱입니다.

ChatGPT가 "이렇게 하면 돼요"라고 알려주는 데 그친다면, 피클은 **직접 전화하고, 주문하고, 예약까지 해줍니다**. 특히 한국 서비스(네이버, 카카오, 쿠팡, KTX)에 깊이 연동되어 있어서, 글로벌 AI 서비스와는 차별화된 실용성을 가집니다.

에이전트 간 대화 기능은 아직 초기 단계지만, "AI끼리 알아서 일정 잡아주는 세상"의 시작점이라는 점에서 흥미롭습니다.

아직 iOS만 지원하고 연동 서비스가 제한적이지만, YC 출신 팀의 실행력을 보면 빠르게 확장될 것으로 기대됩니다.
